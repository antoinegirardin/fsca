## Synthèse
L'avis concerne le kit Thermo Scientific™ Streptex™ Latex Agglutination Test (réf. R30950501, UDI-DI 05056080501376), lot de kit 6416336. L'enzyme d'extraction (lot 6339390) contenue dans ce kit présente une réaction croisée avec le réactif Streptex D Latex (lot 6408670). Cette réaction provoque des résultats faussement négatifs pour le groupe D. Le fabricant juge le risque clinique très faible à négligeable, car Streptex est un test de confirmation et d'autres examens sont nécessaires pour identifier les entérocoques. Les utilisateurs doivent détruire immédiatement le lot concerné et renvoyer le formulaire de réponse client avant le 3 décembre 2026.

## Problème
L'enzyme d'extraction du lot 6339390, contenue dans le produit R30950501 lot 6416336, peut avoir des performances atypiques lorsqu'elle est utilisée avec le réactif Streptex D Latex du lot 6408670. Une réaction croisée a été identifiée : elle entraîne des réactions faussement négatives.

## Cause
Réactions croisées entre l'enzyme d'extraction (lot 6339390) et le réactif D Latex (lot 6408670). Le fabricant signale aussi que le réactif du groupe D du lot 6416336 peut se détériorer au fil du temps.

## Risque
Résultats faussement négatifs pour le sérogroupe D (streptocoques du groupe D / entérocoques), pouvant empêcher l'identification de ce sérogroupe. Selon le fabricant, aucune conséquence sur la santé n'est attendue à court ou à long terme. Streptex n'est qu'un test de confirmation : l'identification des entérocoques repose aussi sur la coloration de Gram, le test à l'esculine biliaire, l'hémolyse sur gélose au sang, etc. La prise en charge du patient ne devrait pas être affectée. Les contrôles qualité positifs et négatifs standard doivent être systématiquement réalisés.
