## Synthèse
Le kit Thermo Scientific™ Streptex™ Latex Agglutination Test (REF R30950501, UDI-DI 05056080501376), lot de kit 6416336, est concerné. L'enzyme d'extraction qu'il contient (lot 6339390) présente une réaction croisée avec le réactif Streptex D Latex (lot 6408670). Cette réaction entraîne des résultats faussement négatifs pour le groupe D. Le fabricant juge le risque clinique très faible à négligeable, car Streptex est un test de confirmation et d'autres tests sont nécessaires pour identifier les entérocoques. Les laboratoires doivent détruire immédiatement le lot concerné. Ils doivent aussi renvoyer le formulaire de réponse avant le 3 décembre 2026.

## Problème
L'enzyme d'extraction du lot 6339390, contenue dans le kit R30950501 lot 6416336, peut présenter des performances atypiques lorsqu'elle est utilisée avec le réactif Streptex D Latex du lot 6408670. Une réaction croisée a été identifiée et entraîne des réactions faussement négatives. Le réactif du groupe D du lot 6416336 peut en outre se détériorer au fil du temps.

## Cause
Réaction croisée entre l'enzyme d'extraction (lot 6339390) et le réactif D Latex (lot 6408670).

## Risque
Résultats faussement négatifs pour le groupe D de Lancefield, d'où une impossibilité d'identifier ce sérogroupe. Selon le fabricant, aucune conséquence sur la santé n'est attendue, ni à court ni à long terme. Streptex n'est qu'un test de confirmation : d'autres examens (Gram, esculine biliaire, hémolyse sur gélose au sang) sont nécessaires pour identifier les entérocoques, et des contrôles qualité positifs et négatifs doivent être systématiquement inclus.
